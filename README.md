## 一、各大平台风控底层机制与避坑规则

### 1. 谷歌 / Gmail 邮箱
- **首登免扫码机制**：优先选择未绑定个人手机与密保的一手纯白号，首次登录通常不触发二维码扫码验证。

- **指纹环境隔离**：建议单环境单 Profile，严禁单 IP 多号批量并发登录，避免因 Canvas、WebRTC 设备指纹关联导致批量连坐。

### 2. 苹果 / 海外 Apple ID
- **严禁在系统设置（iCloud）直接登录**：外区未激活或共享 ID 仅限在 **App Store** 内登录下载应用；直接登录手机“设置”若遇账号被锁将导致整机变砖。
- **更新与付费规范**：使用正规礼品卡充值，保持节点地区与账号国家一致。

### 3. Telegram (TG) / 社媒账号 (X, Instagram)
- **协议与客户端规范**：移动端首次登录尽量使用原生移动代理，避免使用万人骑机房 IP。
- **养号动作**：前 48 小时内仅做正常浏览，切勿高频加群、群发私信或批量拉人。
